# Turnamen eMeL

Aplikasi web sederhana untuk panitia turnamen Mobile Legends, dipakai untuk melihat daftar tim peserta beserta status lolos atau gugurnya. Dibuat memakai Laravel dan Bootstrap sebagai tugas UTS Pemrograman Web 2026.

## Fitur

- Login
- Dashboard (ringkasan jumlah tim, tim lolos, dan tim gugur)
- Halaman pengelolaan (tabel daftar tim peserta)
- Halaman profil pengguna
